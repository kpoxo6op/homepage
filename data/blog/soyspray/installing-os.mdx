I need to install in unattended way because I had 3 nodes, manual install was
not the option. Also I knew I will mess something up later which I have no idea
about and I will need to reinstall the OS time to time until I understand what I
am doing.

## Autoinstall

I picked Ubuntu Server due to its popularity (easy troubleshooting online) and
human friendly YAML file for automatic installation.

It took me some time to understand Canonical customizations on top of Cloud
Init. I have found these notes
https://medium.com/@Phoenixforge/diving-deeper-with-ubuntu-autoinstall-b15e5bdffbb5
invaluable for understanding the Ubuntu autoinstall flavor. In short, the
classic cloud init is wrapped into custom syntax specific to Ubuntu.

I also spent some more time on placing the correct GRUB file to the correct
folder with right content.

ChatGPT had no idea about Canonical customizations so I had to figure it out
myself like it's 2022.

Finally, I after 100th attempt I got presented with the login screen with the
user I expected.

## Get networking sorted

The next issue was Ubuntu Server did not see my networking adapter.

I figured out online the driver support is not added to the Linux Kernel, I have
found the thread where people advised to compile the driver from source.

After some more digging I found the driver source on GitHub. I figured out how
to add the driver compilation commands to Autoinstall.

The next issues was gcc and some other developer tools were not installed by
default on Ubuntu Server. Of course I could not download the required tools from
the Internet to compile th driver because I did not have any network on the OS.

THe way forward was to add the packages required for the compilation in the
installer USB filesystem so Ubuntu can install itself, compile the driver,
install the driver and bring the network ups

selecting the packages from the same distro is critical

kernel freeze is required

disabling suspend on VGA disconnect is required
